## 岗位职责

1. **端到端开发**
   - 负责产品前端和后端的完整功能开发，从需求评审到上线交付
   - 参与系统架构设计，确保系统的可扩展性和稳定性

2. **技术实现**
   - 基于业务需求，选择合适的技术栈进行高效开发
   - 编写高质量、可维护的代码，并进行 Code Review

3. **数据处理**
   - 设计合理的数据库 schema，优化数据查询性能
   - 基于数据驱动，分析和解决业务问题，持续优化产品体验

4. **系统维护**
   - 负责线上服务的稳定性和性能优化
   - 排查和解决生产环境的技术问题

## 任职要求

### 硬性要求
1. **多语言开发能力**
   - 熟练使用至少两门编程语言（如 JavaScript/TypeScript + Python/Java/Go 等）
   - 能够根据业务场景选择合适的技术方案

2. **中间件经验**
   - 熟悉常见中间件的使用场景，如 Redis、消息队列（Kafka/RabbitMQ）、Elasticsearch 等
   - 了解缓存策略、异步处理、搜索索引等技术在实际业务中的应用

3. **数据敏感度**
   - 对数据有敏锐的洞察力，能够通过数据分析发现问题和机会
   - 熟悉 SQL，能够编写高效的查询语句，具备基础的数据分析能力

4. **工程基础**
   - 3 年以上开发经验，计算机相关专业优先
   - 熟悉常用的设计模式和软件工程最佳实践
   - 了解微服务架构或分布式系统的基本概念

### 加分项
- 有 AI/LLM 应用开发经验
- 熟悉云原生技术（Docker、Kubernetes）
- 有开源项目贡献或技术博客
- 具备产品思维，能够从用户角度思考技术方案
