# 第一部分：系统总览

## 1. 项目背景

### 1.1 产品介绍
**月见**是一个集星座、塔罗、占星于一体的玄学类App，包含：
- **月见App**: 主应用（iOS/Android）
- **月见塔罗**: 塔罗占卜功能
- **百度H5**: 小程序/H5版本

### 1.2 系统架构

# 第二部分：核心功能模块

## 3. 用户与权益系统

### 3.1 功能概述
用户权益系统是核心业务模块，用于管理用户的VIP状态、解惑之钥（使用次数）、星盘卡等虚拟资产。

### 3.2 管理后台功能 (moon-qianduan)

#### 3.2.1 权益配置页面
| 功能 | 说明 |
|------|------|
| 用户查询 | 通过手机号/邀请码/用户ID查询 |
| 用户信息展示 | 基础资料、星座信息、出生信息 |
| 权益展示 | 免费次数、解惑之钥、星盘卡、VIP状态 |
| 增加解惑之钥 | 给用户增加使用次数（1-10个） |
| 开通会员 | 开通周度/月度/年度VIP |

**页面路径**: `/benefit/assign`

#### 3.2.2 批量补偿工具 (moon-static)
| 功能 | 说明 |
|------|------|
| 时间选择 | 选择起始和结束时间 |
| 批量补偿 | 对时间段内用户进行权益补偿 |
| 结果反馈 | 显示补偿成功数量和失败信息 |

**页面路径**: `/compensate/index.html`
