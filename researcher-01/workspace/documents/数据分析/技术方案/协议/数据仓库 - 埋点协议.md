# 埋点协议

## 1. 协议概述

### 1.1 设计目标

- **统一标准**：支持 iOS、Android、小程序等多端统一上报
- **可扩展**：支持自定义属性和业务扩展
- **高性能**：轻量级协议，降低网络开销
- **易理解**：字段语义清晰，降低接入成本

### 1.2 协议版本

- **当前版本**：`v1.0`
- **版本字段**：`protocol_version`

|---|---|---|---|

| 批量事件上报 | /batch/collect | POST | application/json |

### 2.3 接口文档

- [单条事件上报](https://app.apifox.com/link/project/4347867/apis/api-427790191)
- [批量事件上报](https://app.apifox.com/link/project/4347867/apis/api-427790192)

### 2.4 上报策略

| **事件类型** | **上报方式** | **策略** |
|---|---|---|
| app_startup | 单条实时上报 | 事件触发后立即上报 |
| app_shutdown | 批量上报 | 本地缓存，每 30s 或累计 10 条时上报 |
| 其他事件 | 批量上报 | 本地缓存，每 30s 或累计 10 条时上报 |

**失败处理：**

- 上报失败的事件写入本地持久化队列（SQLite 或文件）
- 网络恢复后自动重传
- 队列上限 1000 条，超出后丢弃最早的事件
- 事件最大保留 7 天，超期丢弃

## 3. 数据传输格式

### 3.1 HTTP Header 定义（公共参数）

所有埋点请求必须通过 HTTP Header 传递以下公共参数：

| **字段名** | **类型** | **必填** | **说明** | **示例** |
|---|---|---|---|---|
| X-Request-Id | String | 是 | 请求唯一ID（UUID） | req_abc123def456 |
| X-Device-Id | String | 是 | 设备唯一标识 | d_abc123def456 |
| X-Device-Model | String | 是 | 设备型号 | iPhone 15 Pro |
| X-Os-Type | String | 是 | 操作系统标识，枚举值见 3.1.1 | iOS / Android |
| X-Os-Version | String | 是 | 操作系统版本 | 17.0 / 14.0 |
| X-App-Version-Name | String | 是 | 版本名称 | 1.2.3 |
| X-App-Version-Code | String | 是 | 版本号代码 | 123 |
| X-Network-Type | String | 是 | 网络类型，枚举值见 3.1.2 | wifi / 4g / 5g |
| X-Time-Zone | String | 是 | 时区（IANA格式） | Asia/Shanghai |
| Accept-Language | String | 是 | 用户语言偏好 | zh-CN / en-US |
| X-Device-Type | String | 是 | 设备类型，枚举值见 3.1.3 | iphone / android |
| X-Track-Protocol | String | 是 | 协议版本 | 1 |
| X-Track-SDK | String | 是 | SDK标识 | ios-1.2.3 / android-1.2.3 |
| Authorization | String | 否 | 用户身份令牌 | Bearer eyJhbG... |
| X-Carrier | String | 否 | 运营商 | 中国移动 |
| X-Distribution | String | 否 | 分发渠道 | AppStore / HuaweiAppGallery |

#### 3.1.1 X-Os-Type（操作系统类型）

| **值** | **说明** |
|---|---|
| iOS | 苹果iOS系统 |
| Android | 安卓系统 |
| Web | Web端 |
| miniapp_wechat | 微信小程序 |
| miniapp_alipay | 支付宝小程序 |

#### 3.1.2 X-Network-Type（网络类型）

| **值** | **说明** |
|---|---|
| wifi | WiFi网络 |
| 5g | 5G移动网络 |
| 4g | 4G移动网络 |
| 3g | 3G移动网络 |
| 2g | 2G移动网络 |
| unknown | 未知网络类型 |

#### 3.1.3 X-Device-Type（设备类型）

| **值** | **含义** |
|---|---|
| iphone | iPhone |
| android | Android |
| wechat_app | 微信小程序 |

### 3.2 请求体（Request Body）字段

事件数据通过 JSON 格式放在请求体中：

| **字段名** | **类型** | **必填** | **说明** | **示例** |
|---|---|---|---|---|
| event_id | String | 是 | 事件唯一ID（UUID） | evt_7d3f8a2e1b5c |
| event_type | String | 是 | 事件类型，枚举值见 3.3 | page_view / click |
| event_name | String | 是 | 事件名称，命名规范见第5章 | home_page |
| timestamp | Long | 是 | 事件发生时间戳（毫秒） | 1710123456789 |
| session_id | String | 是 | 会话ID | sess_x9y8z7w6v5u4 |
| protocol_version | String | 是 | 协议版本号 | 1.0 |
| context | Object | 否 | 事件上下文，字段定义见 3.4～3.6 | {} |
| properties | Object | 否 | 自定义属性，规范见 3.8 | {} |

### 3.3 事件类型（event_type）

| **类型** | **说明** | **触发时机** | **上下文字段** |
|---|---|---|---|
| app_startup | 应用启动 | 应用启动 | 见 3.4 |
| app_shutdown | 应用停止 | APP 退到后台或被终止 | 见 3.4 |
| user_register | 用户注册 | 注册完成后 | - |
| user_login | 用户登录成功 | 用户登录成功后 | - |
| page_view | 页面浏览 | 进入页面时 | 见 3.5 |
| page_exit | 页面离开 | 离开页面时 | 见 3.5 |
| click | 点击事件 | 用户点击时 | 见 3.6 |

#### 3.3.1 app_startup 详细定义

**触发时机：**
- 冷启动：APP 进程被创建（applicationDidFinishLaunching）
- 热启动：APP 从后台切回前台（applicationWillEnterForeground），且距上次进入后台 ≥ 30s（避免快速切换重复计数）

**自定义属性（properties）：**
- `type`: String，"cold" \| "hot"

#### 3.3.2 app_shutdown 详细定义

**触发时机：**
- APP 退到后台（applicationDidEnterBackground）
- APP 被系统终止（需下次启动时补发）

**自定义属性（properties）：**
- `duration_ms`: Long，本次前台停留时长（毫秒）

#### 3.3.3 page_view 详细定义

**触发时机：**
- 用户进入功能页面时触发（仅记录入口，不记录详细交互）

**说明：**
Phase 1 只统计是否进入，不统计完成率等深度指标。目的是分析"用了核心功能的用户"和"没用的用户"留存率差异，为后续功能优化提供方向判断。

### 3.4 应用启动/停止字段（app_startup / app_shutdown）

| **字段名** | **类型** | **必填** | **说明** | **示例** |
|---|---|---|---|---|
| launch_type | String | 是 | 启动类型：cold（冷启动）/ warm（热启动） | cold |
| referrer | String | 否 | 启动来源（如推送通知、外链唤起等） | push_notification |

### 3.5 页面相关字段（page_view / page_exit）

| **字段名** | **类型** | **必填** | **说明** | **示例** |
|---|---|---|---|---|
| page_name | String | 是 | 页面名称（英文标识），命名规范见 5.1 | home_page |
| page_title | String | 是 | 页面标题（中文可读） | 首页 |
| referrer_page | String | 否 | 来源页面 | splash_page |
| stay_duration | Int | 否 | 停留时长（ms，page_exit 时填写） | 15000 |

### 3.6 点击相关字段（click）

| **字段名** | **类型** | **必填** | **说明** | **示例** |
|---|---|---|---|---|
| element_id | String | 是 | 元素ID，命名规范见 5.2 | btn_login_wechat |
| element_name | String | 是 | 元素名称 | 微信登录按钮 |
| element_type | String | 是 | 元素类型，枚举值见 3.6.1 | button / image / text |
| element_position | String | 否 | 元素位置（列表索引等） | 3 |
| page_name | String | 是 | 所在页面 | login_page |

#### 3.6.1 element_type（元素类型）

| **值** | **说明** |
|---|---|
| button | 按钮 |
| image | 图片 |
| text | 文本 |
| input | 输入框 |
| list_item | 列表项 |
| banner | 轮播图/Banner |
| tab | 标签页 |

### 3.7 用户相关字段（user_register / user_login）

| **字段名** | **类型** | **必填** | **说明** | **示例** |
|---|---|---|---|---|
| user_id | String | 是 | 用户唯一标识 | u_abc123def456 |
| login_type | String | 否 | 登录方式（user_login 时） | wechat / phone / email |

### 3.8 扩展字段（properties）

所有事件可携带自定义属性：

```json
{
  "properties": {
    "category": "category",
    "product_id": "12345",
    "price": 2999.00
  }
}
```

**自定义属性规范：**

- 属性名：小写，下划线分隔，如 `product_id`
- 属性值：支持 String、Number、Boolean、Array
- 禁止嵌套对象（扁平化设计）
- 单个事件属性数量建议 < 20 个

## 6. 数据质量规范

### 6.1 字段校验规则

**HTTP Header 校验：**

| **校验项** | **规则** | **处理方式** |
|---|---|---|
| 必填 Header 缺失 | X-Os-Type、X-App-Version-Name 等 | 返回 400 错误 |
| Header 格式错误 | X-Os-Type 不在枚举范围内 | 记录错误，尝试校正 |
| Authorization 无效 | Token 过期或格式错误 | 按未登录处理 |

**请求体校验：**

| **校验项** | **规则** | **处理方式** |
|---|---|---|
| 必填字段缺失 | event_id、event_type、timestamp 等 | 记录错误日志，丢弃事件，监控告警 |
| 时间戳异常 | 超过当前时间 1 小时或早于 7 天 | 服务端校正或丢弃 |
| event_id 重复 | 服务端去重（24小时窗口） | 幂等处理 |
| 字段类型错误 | 类型不符合定义 | 尝试转换，失败则丢弃，记录错误 |

### 6.2 采样策略

| **场景** | **采样率** | **说明** |
|---|---|---|
| 正常事件 | 100% | 全量采集 |
| swipe 滑动 | 10% | 高频事件采样 |
| 崩溃日志 | 100% | 全量采集 |
| debug 模式 | 100% | 开发测试全量 |
