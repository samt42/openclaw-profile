# 实时查询协议

## 1. 协议定义

实时查询直读 Redis，不经过聚合查询链路，提供秒级延迟的在线数据查询能力。所有实时查询统一通过以下接口发起：

```http
POST /query
Content-Type: application/json
```

**请求体结构**:

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| business | string | 是 | 业务域，见下方枚举 |
| last_minutes | int | 否 | 查询最近N分钟的数据，默认5，最大60 |
| dimensions | array\<string\> | 否 | 分组维度字段列表，为空则不分组 |
| metrics | array\<object\> | 是 | 指标定义列表，至少一个 |
| metrics[].field | string | 是 | 指标字段名 |
| metrics[].aggregation | string | 是 | 聚合函数：`summary` / `count` / `distinct_count` / `avg` / `max` / `min` |
| metrics[].alias | string | 否 | 响应中该指标的别名 |
| filters | array\<object\> | 否 | 过滤条件列表，多个条件取 AND |
| filters[].field | string | 是 | 过滤字段名 |
| filters[].operator | string | 是 | 操作符：`=` / `!=` / `>` / `>=` / `<` / `<=` / `in` / `not_in` |
| filters[].value | any | 是 | 过滤值，`in` / `not_in` 时为数组 |

**business 枚举**:

| 值              | 说明      |
| -------------- | ------- |
| `online_users` | 当前在线用户数 |

## 2. 示例

### 2.1 实时在线用户数

```json
{
    "business": "online_users",
    "metrics": [
        {"field": "online_count", "aggregation": "count", "alias": "online_users"}
    ]
}
```

**响应示例**:
```json
{
    "code": 0,
    "message": "success",
    "data": {
        "business": "online_users",
        "rows": [
            {"online_users": 12345, "update_time": "2026-03-16T10:30:00Z"}
        ],
        "total": 1
    }
}
```

## 3. 响应规范

### 3.1 统一响应格式

```json
{
    "code": 0,
    "message": "success",
    "data": {}
}
```

### 3.2 错误码定义

| 错误码 | 含义 | HTTP 状态码 |
|--------|------|-------------|
| 0 | 成功 | 200 |
| 40001 | 参数错误 | 400 |
| 40101 | 未授权 | 401 |
| 40301 | 无权限访问 | 403 |
| 50001 | 内部错误 | 500 |


## 4. 性能要求

| business | 响应时间要求 | 说明 |
|--------|-------------|------|
| `online_users` | < 50ms | Redis SCARD 直读 |
| last_minutes 上限 | 60 分钟 | 超出返回 `40001` |
