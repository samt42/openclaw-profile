## 1. 数据分层概览

| 分层 | 全称 | 说明 | 保留周期 |
|------|------|------|----------|
| ODS | Operational Data Store | 原始数据，与数据源保持一致 | 7-30天 |
| DWD | Data Warehouse Detail | 清洗后的明细数据，统一格式 | 90天-1年 |
| DWS | Data Warehouse Service | 轻度汇总，按维度聚合 | 1-2年 |
| ADS | Application Data Service | 应用数据，直接面向报表/API | 90天-永久 |

## 2. ODS 层 - 原始数据接入

### 2.1 ods_tracking_event_raw - 埋点事件原始数据

存储埋点协议上报的原始事件数据，包含HTTP Header和Body中的所有字段。

| 字段名              | 类型          | 说明        | 来源                        |
| ---------------- | ----------- | --------- | ------------------------- |
| id               | BIGINT      | 自增ID      | 系统生成                      |
| event_type       | VARCHAR(32) | 事件类型      | Body.event_type           |
| event_name       | VARCHAR(32) | 事件名称      | Body.event_name           |
| event_time       | BIGINT      | 事件时间戳(毫秒) | Body.timestamp            |
| request_id       | VARCHAR(64) | 请求ID      | Header.X-Request-Id       |
| device_id        | VARCHAR(64) | 设备指纹      | 服务端生成                     |
| device_model     | VARCHAR(64) | 设备型号      | Header.X-Device-Model     |
| user_id          | VARCHAR(32) | 用户ID      | 从Authorization解析          |
| platform         | VARCHAR(16) | 平台        | Header.X-Os-Type          |
| os_version       | VARCHAR(16) | 系统版本      | Header.X-Os-Version       |
| app_version      | VARCHAR(16) | APP版本名称   | Header.X-App-Version-Name |
| app_version_code | VARCHAR(16) | APP版本号    | Header.X-App-Version-Code |
| channel          | VARCHAR(32) | 分发渠道      | Header.X-Distribution     |
| network_type     | VARCHAR(16) | 网络类型      | Header.X-Network-Type     |
| carrier          | VARCHAR(32) | 运营商       | Body.carrier              |
| time_zone        | VARCHAR(32) | 时区        | Header.X-Time-Zone        |
| language         | VARCHAR(16) | 语言        | Header.Accept-Language    |
| device_type      | VARCHAR(8)  | 设备类型      | Header.X-Device-Type      |
| protocol_version | VARCHAR(8)  | 协议版本      | Body.protocol_version     |
| properties       | JSON        | 自定义属性     | Body.properties           |
| dt     | DATETIME    | 接收时间      | 服务端生成                     |

```sql
CREATE TABLE IF NOT EXISTS `ods_tracking_event_raw` (
    `id` BIGINT UNSIGNED AUTO_INCREMENT,
    `event_type` VARCHAR(32) NOT NULL COMMENT '事件类型: page_view/click/exposure等',
    `event_name` VARCHAR(32) NOT NULL COMMENT '事件名称',
    `event_time` BIGINT UNSIGNED NOT NULL COMMENT '事件发生时间戳(毫秒)',
    `request_id` VARCHAR(64) COMMENT '请求ID(Header.X-Request-Id)',
    `device_id` VARCHAR(64) COMMENT '设备指纹(服务端生成)',
    `device_model` VARCHAR(64) COMMENT '设备型号(Header.X-Device-Model)',
    `user_id` VARCHAR(32) COMMENT '用户ID(从Authorization解析)',
    `platform` VARCHAR(16) NOT NULL COMMENT '平台: ios/android/web(Header.X-Os-Type)',
    `os_version` VARCHAR(16) COMMENT '系统版本(Header.X-Os-Version)',
    `app_version` VARCHAR(16) COMMENT 'APP版本名称(Header.X-App-Version-Name)',
    `app_version_code` VARCHAR(16) COMMENT 'APP版本号(Header.X-App-Version-Code)',
    `channel` VARCHAR(32) COMMENT '分发渠道(Header.X-Distribution)',
    `network_type` VARCHAR(16) COMMENT '网络类型(Header.X-Network-Type)',
    `carrier` VARCHAR(32) COMMENT '运营商(Body.carrier)',
    `time_zone` VARCHAR(32) COMMENT '时区(Header.X-Time-Zone)',
    `language` VARCHAR(16) COMMENT '语言(Header.Accept-Language)',
    `device_type` VARCHAR(8) COMMENT '设备类型(Header.X-Device-Type)',
    `protocol_version` VARCHAR(8) COMMENT '协议版本(Body)',
    `properties` JSON COMMENT '自定义属性JSON(Body.properties)',
    `dt` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '数据接收时间',
    PRIMARY KEY (`id`),
    KEY `idx_event_time` (`event_time`),
    KEY `idx_request_id` (`request_id`),
    KEY `idx_user_id` (`user_id`),
    KEY `idx_event_type` (`event_type`),
    KEY `idx_event_name` (`event_name`),
    KEY `idx_device_model` (`device_model`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='埋点事件原始数据';
```

```sql
    page_title VARCHAR(200) COMMENT '页面标题',
```

## 4. DWS 层 - 汇总数据

| 字段名 | 类型 | 说明 |

| page_path | VARCHAR(500) | 页面路径 |
| platform | VARCHAR(20) | 平台 |
| app_version | VARCHAR(20) | APP版本 |
| channel | VARCHAR(50) | 渠道 |
| pv_count | BIGINT | 页面浏览量 |
| uv_count | BIGINT | 独立访客数 |
| ip_count | BIGINT | 独立IP数 |
| total_duration | BIGINT | 总停留时长(秒) |
| avg_duration | DECIMAL(10,2) | 平均停留时长 |
| max_duration | INT | 最大停留时长 |
| entrance_count | BIGINT | 作为入口页次数 |
| exit_count | BIGINT | 退出页次数 |
| bounce_count | BIGINT | 跳出次数 |
| bounce_rate | DECIMAL(5,2) | 跳出率(%) |
| direct_count | BIGINT | 直接访问数 |
| external_count | BIGINT | 外部链接数 |
| internal_count | BIGINT | 内部跳转数 |
| new_user_pv | BIGINT | 新用户PV |
| old_user_pv | BIGINT | 老用户PV |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

```sql
CREATE TABLE dws_page_view_dm (
    id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '自增ID',
    stat_date DATE NOT NULL COMMENT '统计日期',
    page_path VARCHAR(500) NOT NULL COMMENT '页面路径',
    platform VARCHAR(20) COMMENT '平台',
    app_version VARCHAR(20) COMMENT 'APP版本',
    channel VARCHAR(50) COMMENT '渠道',
    pv_count BIGINT DEFAULT 0 COMMENT '页面浏览量',
    uv_count BIGINT DEFAULT 0 COMMENT '独立访客数',
    ip_count BIGINT DEFAULT 0 COMMENT '独立IP数',
    total_duration BIGINT DEFAULT 0 COMMENT '总停留时长(秒)',
    avg_duration DECIMAL(10,2) DEFAULT 0 COMMENT '平均停留时长',
    max_duration INT DEFAULT 0 COMMENT '最大停留时长',
    entrance_count BIGINT DEFAULT 0 COMMENT '作为入口页次数',
    exit_count BIGINT DEFAULT 0 COMMENT '退出页次数',
    bounce_count BIGINT DEFAULT 0 COMMENT '跳出次数',
    bounce_rate DECIMAL(5,2) DEFAULT 0 COMMENT '跳出率(%)',
    direct_count BIGINT DEFAULT 0 COMMENT '直接访问数',
    external_count BIGINT DEFAULT 0 COMMENT '外部链接数',
    internal_count BIGINT DEFAULT 0 COMMENT '内部跳转数',
    new_user_pv BIGINT DEFAULT 0 COMMENT '新用户PV',
    old_user_pv BIGINT DEFAULT 0 COMMENT '老用户PV',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (id),
    UNIQUE KEY uk_stat_page (stat_date, page_path, platform, app_version),
    KEY idx_stat_date (stat_date),
    KEY idx_page_path (page_path(100))
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='页面访问汇总表';
```

```sql
CREATE TABLE dws_user_behavior_dm (
```

| created_at | DATETIME | 创建时间 |
| expire_at | DATETIME | 缓存过期时间 |

```sql
CREATE TABLE IF NOT EXISTS `ads_retention_report` (
    `report_id` VARCHAR(64) NOT NULL COMMENT '报表ID(md5)',

```

### 5.2 ads_retention_cohort - 同期群分析表

存储同期群（Cohort）分析数据。

| 字段名 | 类型 | 说明 |

| cohort_date | DATE | 同期群日期（首次登录日期） |
| cohort_type | VARCHAR(16) | 留存类型: new_user |
| channel | VARCHAR(32) | 渠道 |
| platform | VARCHAR(16) | 平台 |
| cohort_size | BIGINT | 同期群规模 |
| retention_matrix | JSON | 留存矩阵 |
| created_at | DATETIME | 创建时间 |

```sql
CREATE TABLE ads_retention_cohort (
    id BIGINT NOT NULL AUTO_INCREMENT COMMENT '自增ID',
    cohort_date DATE NOT NULL COMMENT '同期群日期（首次登录日期）',
    cohort_type VARCHAR(16) NOT NULL COMMENT '留存类型: new_user',
    channel VARCHAR(32) NOT NULL COMMENT '渠道',
    platform VARCHAR(16) NOT NULL COMMENT '平台',
    cohort_size BIGINT DEFAULT 0 COMMENT '同期群规模',
    retention_matrix JSON COMMENT '留存矩阵',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    PRIMARY KEY (id),
```

## 6. 索引规范

### 6.1 通用索引命名规范

| 索引类型 | 命名格式 | 示例 |
|----------|----------|------|
| 主键 | `pk_{表名}` 或默认PRIMARY | PRIMARY KEY (id) |
| 唯一索引 | `uk_{字段组合}` | uk_user_active (user_id, active_date) |
| 普通索引 | `idx_{字段名}` | idx_event_name, idx_dt |
| 联合索引 | `idx_{字段1}_{字段2}` | idx_channel_platform |

### 6.2 分层索引建议

```sql
-- ODS 层索引（高频查询字段）
-- 优先: user_id, event_time

-- DWS 层索引（报表查询优化）
ALTER TABLE dws_user_retention
ADD INDEX idx_first_login_date (first_login_date),
ADD INDEX idx_channel_platform (channel, platform);
```


## 7. 分区策略

### 7.1 分区字段选择

| 分层 | 分区字段 | 分区类型 | 分区粒度 |
|------|----------|----------|----------|
| ODS | dt | RANGE | 按月 |
| DWD | dt | RANGE | 按月 |
| DWS | stat_date | 不分区或按年 | - |
| ADS | - | 不分区 | - |

### 7.2 分区维护脚本

```sql
-- 添加新分区（按月）
ALTER TABLE dwd_tracking_event_di
ADD PARTITION (
    PARTITION p202407 VALUES LESS THAN (202408)
);

-- 删除过期分区
ALTER TABLE dwd_tracking_event_di
DROP PARTITION p202401;

-- 查看分区信息
SELECT
    partition_name,
    from_days(partition_description) as partition_range
FROM information_schema.partitions
WHERE table_name = 'dwd_tracking_event_di';
```

## 8. 性能优化

### 8.1 索引优化

```sql
-- DWS 层索引
ALTER TABLE dws_user_retention
ADD INDEX idx_first_login_date (first_login_date),
ADD INDEX idx_channel_platform (channel, platform);
```

### 8.2 分区策略

- ODS/DWD 层按 `dt` 字段 RANGE 分区，按月一个分区
- DWS 层数据量小，按年分区或不分区

### 8.3 查询优化

- 报表查询优先走 ADS 层缓存表
- DWS 层查询需限制时间范围
- 禁止直接查询 DWD 明细表做聚合
