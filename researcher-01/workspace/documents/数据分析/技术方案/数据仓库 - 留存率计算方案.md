## 2. 设计目标

- **新用户留存（账号级）**：基于 user_id，统计新用户留存率
- **支持留存周期**：D1（次日）/ D7（7日）/ D30（30日）
- **支持分析维度**：整体 / 渠道 / 平台 / 版本


## 3. ETL 计算流程

### 3.1 数据流

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│  埋点事件数据    │     │  用户注册数据    │     │   计算结果      │
│(user_login等)  │     │  (first_login)  │     │                 │
└────────┬────────┘     └────────┬────────┘     └─────────────────┘
         │                       │
         └───────────┬───────────┘
                     ▼
            ┌─────────────────┐
            │ dwd_user_active │
            │    _daily       │
            │  (用户日活跃)    │
            └────────┬────────┘
                     │
                     ▼
            ┌─────────────────┐
            │ dws_new_user_   │
            │   retention     │
            │ (新用户留存汇总) │
            └────────┬────────┘
                     │
         ┌───────────┼───────────┐
         ▼           ▼           ▼
┌─────────────────┐ ┌─────────────────┐ ┌─────────────────┐
│ ads_retention_  │ │ ads_retention_  │ │ ads_retention_  │
│    report       │ │    cohort       │ │    alert        │
│   (报表缓存)     │ │  (同期群分析)    │ │   (预警表)      │
└─────────────────┘ └─────────────────┘ └─────────────────┘
```

### 3.2 每日调度计划

```
Step 1: ODS → DWD 数据清洗 (凌晨 01:00)
  ods_tracking_event_raw + ods_user_register_raw → dwd_user_active_daily

Step 2: DWD → DWS 轻度汇总 (凌晨 02:00)
  dwd_user_active_daily → dws_new_user_daily

Step 3: 留存核心计算 (凌晨 03:00)
  dws_new_user_daily + dwd_user_active_daily → dws_new_user_retention

Step 4: ADS 报表生成 (凌晨 04:00)
  → ads_retention_cohort（同期群分析）
  → ads_retention_alert（留存异常检测）
```


## 4. 核心计算 SQL

### 4.1 新用户留存率计算

```sql
-- 新用户留存率计算（基于 user_id 和 first_login_date）
INSERT INTO dws_new_user_retention
SELECT
  first_login_date,
  'ALL', 'ALL', 'ALL',  -- 维度（channel, platform, version）
  COUNT(DISTINCT user_id) as new_users,
  COUNT(DISTINCT CASE WHEN user_age_days = 1 THEN user_id END) as d1_retained,
  COUNT(DISTINCT CASE WHEN user_age_days = 7 THEN user_id END) as d7_retained,
  COUNT(DISTINCT CASE WHEN user_age_days = 30 THEN user_id END) as d30_retained,
  COUNT(DISTINCT CASE WHEN user_age_days = 1 THEN user_id END) * 100.0
    / COUNT(DISTINCT user_id) as d1_rate,
  COUNT(DISTINCT CASE WHEN user_age_days = 7 THEN user_id END) * 100.0
    / COUNT(DISTINCT user_id) as d7_rate,
  COUNT(DISTINCT CASE WHEN user_age_days = 30 THEN user_id END) * 100.0
    / COUNT(DISTINCT user_id) as d30_rate
FROM dwd_user_active_daily
WHERE first_login_date = '${biz_date}'
GROUP BY first_login_date;
```


## 5. 常用查询示例

### 5.1 近30天新用户留存趋势

```sql
SELECT
  first_login_date,
  new_users,
  d1_rate,
  d7_rate,
  d30_rate
FROM dws_new_user_retention
WHERE first_login_date >= DATE_SUB(CURDATE(), INTERVAL 30 DAY)
  AND channel = 'ALL' AND platform = 'ALL'
ORDER BY first_login_date;
```

### 5.2 各渠道新用户留存对比

```sql
SELECT
  channel,
  AVG(d1_rate) as avg_d1,
  AVG(d7_rate) as avg_d7,
  AVG(d30_rate) as avg_d30
FROM dws_new_user_retention
WHERE first_login_date >= DATE_SUB(CURDATE(), INTERVAL 7 DAY)
  AND channel != 'ALL'
GROUP BY channel
ORDER BY avg_d7 DESC;
```
