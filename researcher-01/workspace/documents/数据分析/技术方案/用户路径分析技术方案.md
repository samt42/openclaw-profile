### 2.2 核心表结构

> **详细设计文档**: [数据仓库 - 整体设计](数据仓库%20-%20整体设计.md#33-核心表结构)

本文档仅列出核心字段，完整的DDL脚本请参见：
- [数据仓库 - 整体设计](数据仓库%20-%20整体设计.md) - 详细表结构文档
- [数据仓库 - 数据库设计](数据/数据仓库%20-%20数据库设计.md) - 完整 DDL 脚本

#### DWS 层

**dws_user_path_dm** (用户路径分析表)

完整字段定义和 DDL 详见 [数据仓库 - 数据库设计](数据/数据仓库%20-%20数据库设计.md)。

核心字段说明：

| 字段 | 说明 |
|------|------|
| path_id | 路径分析ID |
| start_event | 起始事件 |
| path_depth | 路径深度 |
| path_sequence | 事件序列 |
| user_count | 走此路径的用户数 |
| conversion_rate | 路径转化率 |
| avg_duration_ms | 平均完成时长(毫秒) |
