# 用户路径分析

## 1. 背景与目标

### 1.1 问题背景

用户在 App 内的行为路径复杂多样，当前缺乏有效的工具来可视化和分析用户的真实使用模式。运营团队难以了解用户从进入应用到完成核心功能的完整路径，无法发现用户流失的关键节点和优化机会。

### 1.2 目标

- 建立标准化的用户路径分析体系，支持可视化用户行为流转
- 构建可扩展的路径数据模型，支持秒级查询响应
- 支持桑基图展示用户流转，直观发现路径瓶颈
- 支持路径深度自定义（3-10步），灵活分析不同场景
- 支持起始事件/结束事件分析，聚焦关键转化路径
- 支持路径转化率计算，量化各步骤转化效果


## 2. 指标定义

### 2.1 路径分析类型

#### 用户行为路径（账号级）

| 项目 | 说明 |
|------|------|
| **定义** | 用户在指定时间窗口内，按时间顺序触发的一系列事件序列 |
| **计算口径** | 基于 session_id 或 user_id，按事件发生时间排序生成路径 |
| **用户标识** | 使用 user_id（账号级唯一标识）结合 session_id |
| **支持深度** | 3-10步，默认5步 |

### 2.2 路径分析示例

```
典型用户路径示例：

首页浏览 → 商品列表 → 商品详情 → 加入购物车 → 订单确认

路径转化率计算：
- 从首页到商品列表：60%（6000/10000）
- 从商品列表到商品详情：50%（3000/6000）
- 从商品详情到加购：40%（1200/3000）
- 从加购到订单确认：30%（360/1200）
- 整体转化率：3.6%（360/10000）
```

### 2.3 特殊说明

| 场景 | 处理方式 |
|----------|------|
| **跨会话路径** | 同一 user_id 在不同 session 中的行为独立计算路径 |
| **路径中断** | 超过30分钟无事件视为路径结束，新事件开启新路径 |
| **循环路径** | 同一页面多次访问在路径中重复显示，不做去重 |


## 3. 用户身份

| ID 类型 | 标识符 | 生成时机 | 使用场景 |
|---------|--------|----------|----------|
| **用户 ID** | user_id | 注册/登录后由服务端返回 | 账号级路径分析 |
| **会话 ID** | session_id | 应用启动或会话超时时生成 | 单次访问路径分析 |

## 4. 埋点事件设计

### 4.1 事件列表

| 事件名 | 事件显示名 | 触发时机 | 使用场景 |
|--------|-----------|----------|----------|
| **page_view** | 页面浏览 | 进入页面时 | 路径起点、流转节点 |
| **page_exit** | 页面离开 | 离开页面时 | 路径终点、计算停留时长 |
| **click** | 点击事件 | 用户点击时 | 路径中的交互节点 |
| **exposure** | 曝光事件 | 元素出现在可视区域 | 可选路径补充 |

### 4.2 事件上下文定义

**page_view / page_exit 事件上下文**

| 属性名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| `context.page_name` | string | 页面名称 | "home_page" |
| `context.page_title` | string | 页面标题 | "首页" |
| `context.page_path` | string | 页面路径 | "/pages/home/index" |
| `context.referrer_page` | string | 来源页面 | "splash_page" |

**click 事件上下文**

| 属性名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| `context.element_id` | string | 元素ID | "btn_go_shopping" |
| `context.element_name` | string | 元素名称 | "去购物按钮" |
| `context.page_name` | string | 所在页面 | "home_page" |

### 4.3 埋点协议

> **详细埋点协议**（HTTP Header、请求体格式、API接口、SDK实现、设备ID方案等）请参考：

### 4.4 采集策略

| 事件类型 | 上报策略 | 说明 |
|----------|----------|------|
| page_view / page_exit | **实时上报** | 立即发送，失败则重试3次 |
| click | **实时上报** | 立即发送，失败则重试3次 |
| exposure | **批量上报** | 本地聚合后批量上报 |

## 6. 报表设计

### 6.1 用户路径桑基图

| 项目 | 内容 |
|------|------|
| **功能** | 可视化展示用户从起始事件到后续事件的流转分布 |
| **维度** | 起始事件、路径深度、平台、日期 |
| **指标** | 用户数、转化率、平均停留时长 |
| **图表类型** | 桑基图（Sankey Diagram） |

### 6.2 路径漏斗分析

| 项目 | 内容 |
|------|------|
| **功能** | 分析指定路径各步骤的转化情况 |
| **维度** | 路径步骤、事件类型、平台 |
| **指标** | 每步用户数、步骤转化率、整体转化率、流失率 |
| **图表类型** | 漏斗图 + 折线图 |

### 6.3 热门路径排行榜

| 项目 | 内容 |
|------|------|
| **功能** | 展示最常走的热门路径TOP N |
| **维度** | 路径序列、起始事件、终止事件 |
| **指标** | 用户数占比、平均时长、转化率 |
| **图表类型** | 表格 + 条形图 |
