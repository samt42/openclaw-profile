# 功能使用率分析

## 1. 背景与目标

### 1.1 问题背景

产品迭代过程中缺乏对各功能模块使用情况的系统性了解，无法准确评估功能价值，界面布局和交互设计的优化缺乏数据支撑。同时，新功能上线后的效果难以量化评估。

### 1.2 目标

- 建立标准化的功能使用率分析体系，支持产品优化决策
- 支持页面元素点击热力图，直观展示用户点击分布
- 支持点击率计算（曝光→点击），评估元素吸引力
- 支持功能使用频次分布，识别高频/低频功能
- 支持AB测试效果对比，量化版本差异

## 2. 指标定义

### 2.1 核心指标

| 指标名称 | 定义 | 计算口径 |
|----------|------|----------|
| **曝光量** | 页面/元素被用户看到的次数 | 元素进入可视区域时触发统计 |
| **点击量** | 元素被用户点击的次数 | 元素被点击时触发统计 |
| **点击率 (CTR)** | 点击量 / 曝光量 × 100% | 衡量元素吸引力 |
| **功能使用人数** | 使用该功能的去重用户数 | 按 device_id 或 user_id 去重 |
| **功能使用频次** | 功能的总使用次数 | 累加该功能的触发次数 |
| **人均使用次数** | 功能使用频次 / 功能使用人数 | 衡量功能粘性 |
| **功能渗透率** | 使用该功能的人数 / 总活跃人数 × 100% | 衡量功能覆盖度 |

### 2.2 指标计算示例

```
按钮点击率计算示例：

场景：首页"立即购买"按钮
- 曝光量：100,000次（10万用户看到该按钮）
- 点击量：5,000次
- 点击率 = 5,000 / 100,000 × 100% = 5%

功能使用率计算示例：

场景：搜索功能
- 日活跃用户数：50,000人
- 使用搜索功能的人数：15,000人
- 功能渗透率 = 15,000 / 50,000 × 100% = 30%
- 搜索总次数：45,000次
- 人均使用次数 = 45,000 / 15,000 = 3次/人
```

### 2.3 特殊说明

| 场景 | 处理方式 |
|------|----------|
| **重复曝光** | 同一页面内，元素在一次页面浏览周期内只计一次曝光 |
| **多次点击** | 同一用户多次点击同一元素，每次点击都计入点击量 |
| **页面滚动** | 元素从不可见到可见时触发曝光事件 |
| **AB测试分组** | 按实验ID和分组标识分别统计各组数据 |

## 4. 埋点事件设计

### 4.1 事件列表

| 事件名 | 事件显示名 | 触发时机 | 使用场景 |
|--------|-----------|----------|----------|
| **element_exposure** | 元素曝光 | 元素进入可视区域时 | 点击率计算的分母 |
| **element_click** | 元素点击 | 用户点击元素时 | 点击率计算的分子、热力图 |
| **page_view** | 页面浏览 | 进入页面时 | 页面级功能分析 |
| **feature_use** | 功能使用 | 功能被触发时 | 功能频次统计 |

### 4.2 事件上下文定义

**element_exposure / element_click 事件上下文**

| 属性名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| `context.element_id` | string | 元素唯一标识 | "btn_buy_now" |
| `context.element_name` | string | 元素名称 | "立即购买按钮" |
| `context.element_type` | string | 元素类型 | "button" / "link" / "image" |
| `context.page_name` | string | 所在页面 | "home" / "product_detail" |
| `context.page_path` | string | 页面路径 | "/pages/home" |
| `context.position_x` | float | 元素X坐标 | 120.5 |
| `context.position_y` | float | 元素Y坐标 | 300.0 |
| `context.ab_test_id` | string | AB测试实验ID | "exp_001" |
| `context.ab_group` | string | AB测试分组 | "control" / "treatment" |

**feature_use 事件上下文**

| 属性名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| `context.feature_name` | string | 功能名称 | "search" / "share" / "filter" |
| `context.feature_module` | string | 所属模块 | "home" / "product" / "user" |
| `context.use_duration` | int | 使用时长(ms) | 5000 |

### 4.3 埋点协议

> **详细埋点协议**（HTTP Header、请求体格式、API接口、SDK实现、设备ID方案等）请参考：

> - [数据仓库 - 埋点协议](../../../技术文档/数据仓库/协议/数据仓库%20-%20埋点协议.md)

### 4.4 采集策略

| 事件类型 | 上报策略 | 说明 |
|----------|----------|------|
| element_exposure | **延迟上报** | 批量上报，减少网络请求频率 |
| element_click | **实时上报** | 立即发送，失败则重试3次 |
| feature_use | **实时上报** | 立即发送，失败则重试3次 |

## 6. 报表设计

### 6.1 元素点击热力图

| 项目 | 内容 |
|------|------|
| **功能** | 可视化展示页面各元素的点击热度分布 |
| **维度** | 页面、元素位置(X,Y坐标) |
| **指标** | 点击次数、点击密度 |
| **图表类型** | 热力图、叠加图层 |

### 6.2 点击率分析报表

| 项目 | 内容 |
|------|------|
| **功能** | 展示各页面元素的曝光量和点击量 |
| **维度** | 页面、元素ID、元素名称 |
| **指标** | 曝光量、点击量、点击率(CTR) |
| **图表类型** | 表格、柱状图 |

### 6.3 功能使用频次报表

| 项目 | 内容 |
|------|------|
| **功能** | 展示各功能的使用次数和用户分布 |
| **维度** | 功能名称、模块、日期 |
| **指标** | 使用次数、使用人数、人均次数、功能渗透率 |
| **图表类型** | 柱状图、饼图、趋势图 |

### 6.4 AB测试效果对比报表

| 项目 | 内容 |
|------|------|
| **功能** | 对比不同实验组的点击率/转化率差异 |
| **维度** | 实验ID、分组、日期 |
| **指标** | 各组点击率、转化率、置信区间、显著性检验 |
| **图表类型** | 分组柱状图、趋势对比图 |

### 术语表

| 术语 | 说明 |
|------|------|
| 点击率 (CTR) | Click Through Rate，点击量与曝光量的比值 |
| 热力图 | 通过颜色深浅展示点击密度分布的可视化图表 |
| 功能渗透率 | 使用该功能的用户数占总活跃用户数的比例 |
| 人均使用次数 | 功能总使用次数除以使用该功能的用户数 |
| 曝光量 | 元素被用户看到的次数 |
| AB测试 | 对比两个或多个版本效果的实验方法 |
