# 用户留存率统计

## 1. 背景与目标

### 1.1 问题背景

用户留存是衡量产品健康度的核心指标，当前采用第三方平台用户留存统计能力，口径不清晰，数据准确性存疑。

### 1.2 目标

- 建立标准化的留存分析体系，支持精细化运营决策
- 构建可扩展的留存数据模型，支持秒级查询响应
- 支持同期群（Cohort）分析能力，追踪用户生命周期
- 支持按多维度（渠道、平台、版本）下钻分析留存差异
- 支持新用户留存分析

## 2. 指标定义

### 2.1 留存类型

#### 新用户留存（账号级留存）

| 项目 | 说明 |
|------|------|
| **定义** | 在 T 日完成首次登录的用户，在第 N 日再次登录的比例 |
| **计算口径** | 新用户留存率 = 在 T+N 日登录的用户数 / 在 T 日首次登录的用户总数 × 100% |
| **用户标识** | 使用 user_id（账号级唯一标识） |
| **首期统计** | D1（次日）、D7（7日）、D30（30日） |

### 2.2 留存率计算示例

```
D1 留存率计算：
2月20日首次登录的用户中，2月21日再次登录的比例

D7 留存率计算：
2月20日首次登录的用户中，2月27日再次登录的比例

D30 留存率计算：
2月20日首次登录的用户中，3月22日再次登录的比例
```

### 2.3 特殊说明

| 场景         | 处理方式                                               |
| ---------- | -------------------------------------------------- |
| **登录后注销** | 使用 user_id 关联，只要 device_id 对应过 user_id，后续活跃都算新用户留存 |
| **多设备登录** | 同一 user_id 在多个 device_id 登录，各设备独立计算新用户留存            |

## 4. 埋点事件设计

### 4.1 事件列表

| 事件名 | 事件显示名 | 触发时机 | 使用场景 |
|--------|-----------|----------|----------|
| **user_register** | 用户注册 | 注册成功时 | 新用户留存计算、新增用户统计 |
| **user_login** | 用户登录 | 登录成功时 | 活跃用户统计、新用户留存计算 |

### 4.2 事件上下文定义

**user_register / user_login 事件上下文**

| 属性名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| `context.register_channel` | string | 注册渠道 | "AppStore" |
| `context.login_type` | string | 登录类型 | "password" / "sms" / "wechat" |
| `context.province` | string | 省份 | "北京" |
| `context.city` | string | 城市 | "北京" |

### 4.3 埋点协议

> **详细埋点协议**（HTTP Header、请求体格式、API接口、SDK实现、设备ID方案等）请参考：

> - [数据仓库 - 埋点协议](../../../技术文档/数据仓库/协议/数据仓库%20-%20埋点协议.md)

### 4.4 采集策略

| 事件类型 | 上报策略 | 说明 |
|----------|----------|------|
| user_register / user_login | **实时上报** | 立即发送，失败则重试3次 |

## 6. 报表设计

### 6.1 留存趋势报表

| 项目 | 内容 |
|------|------|
| **功能** | 展示留存率随时间变化趋势 |
| **维度** | 日期 |
| **指标** | 新增设备/用户、D1留存率、D7留存率、D30留存率 |
| **图表类型** | 折线图 |

### 6.2 留存对比报表

| 项目 | 内容 |
|------|------|
| **功能** | 对比不同维度的留存表现 |
| **维度** | 渠道、平台、版本 |
| **指标** | 各维度留存率 |
| **图表类型** | 柱状图/分组柱状图 |

### 6.3 同期群分析报表

| 项目 | 内容 |
|------|------|
| **功能** | 展示用户生命周期留存矩阵 |
| **维度** | 首次登录同期群 × 留存天数 |
| **指标** | 留存率热力图 |
| **图表类型** | 热力图 |
