# 用户中心 - 第三方登录集成方案

## 1. 概述

本文档描述微信、Apple ID 等第三方平台的登录集成方案，包括 OAuth 流程、用户信息获取、账号绑定等。

**支持平台**：
- 微信 (WeChat)
- Apple ID (Sign in with Apple)
- 抖音 (TikTok) - 可选

**相关技术文档**：
- [用户中心 - 注册登录技术方案](用户中心%20-%20注册登录技术方案.md)
- [用户中心 - SSO技术方案](用户中心%20-%20SSO技术方案.md)


## 2. 微信登录

### 2.1 接入方式

| 应用场景 | 接入方式 | 说明 |
|----------|----------|------|
| Web/PC | 微信扫码登录 | 生成二维码，用户扫码授权 |
| iOS/Android | 微信SDK | 唤起微信客户端授权 |
| 微信公众号 | JS-SDK | 微信内网页授权 |
| 小程序 | wx.login | 静默获取用户标识 |


### 2.2 Web 扫码登录流程

```
用户点击"微信登录"按钮
         ↓
后端调用微信接口生成二维码
         ↓
返回二维码 URL 给前端展示
         ↓
用户微信扫码
         ↓
用户确认授权
         ↓
微信回调后端 (携带 code)
         ↓
用 code 换取 access_token
         ↓
用 access_token 获取用户信息
         ↓
查询用户绑定关系
         ↓
已绑定?
   /        \
 是          否
  ↓            ↓
直接登录    创建新用户并绑定
```


### 2.3 移动端 SDK 登录流程

```
用户点击"微信登录"按钮
         ↓
调用微信 SDK 发起授权
         ↓
唤起微信客户端
         ↓
用户确认授权
         ↓
返回 authorization_code
         ↓
后端用 code 换取 access_token
         ↓
获取用户信息
         ↓
处理绑定关系
         ↓
返回登录成功
```


### 2.4 微信 OAuth 接口

**获取二维码**：
```http
GET https://open.weixin.qq.com/connect/qrconnect
  ?appid={appid}
  &redirect_uri={redirect_uri}
  &response_type=code
  &scope=snsapi_login
  &state={state}#wechat_redirect
```

**换取 Access Token**：
```http
GET https://api.weixin.qq.com/sns/oauth2/access_token
  ?appid={appid}
  &secret={secret}
  &code={code}
  &grant_type=authorization_code
```

**获取用户信息**：
```http
GET https://api.weixin.qq.com/sns/userinfo
  ?access_token={access_token}
  &openid={openid}
```


### 2.5 微信返回数据

**Access Token 响应**：
```json
{
  "access_token": "ACCESS_TOKEN",
  "expires_in": 7200,
  "refresh_token": "REFRESH_TOKEN",
  "openid": "OPENID",
  "scope": "SCOPE",
  "unionid": "UNIONID"
}
```

**用户信息响应**：
```json
{
  "openid": "OPENID",
  "nickname": "NICKNAME",
  "sex": 1,
  "language": "zh_CN",
  "city": "Chengdu",
  "province": "Sichuan",
  "country": "CN",
  "headimgurl": "https://thirdwx.qlogo.cn/xxx",
  "privilege": [],
  "unionid": "UNIONID"
}
```

**字段映射**：
| 微信字段 | 系统字段 | 说明 |
|----------|----------|------|
| openid | provider_identifier | 用户唯一标识 |
| unionid | provider_union_id | 跨应用统一标识 |
| nickname | provider_nickname | 昵称 |
| headimgurl | provider_avatar | 头像 |


## 3. Apple ID 登录

### 3.1 接入要求

- iOS 13+ 必须支持 Sign in with Apple
- 需要使用 Apple 提供的 SDK
- 支持"隐藏邮箱"功能


### 3.2 登录流程

```
用户点击"Sign in with Apple"按钮
         ↓
调用 Apple 认证服务 (ASAuthorizationAppleID)
         ↓
用户选择登录方式
   - 使用 Apple ID
   - 隐藏邮箱
         ↓
用户验证 (Face ID / Touch ID / 密码)
         ↓
返回 authorization_code + identity_token
         ↓
验证 identity_token (JWT)
         ↓
获取用户信息 (仅首次)
         ↓
查询绑定关系
         ↓
处理登录/注册
```


### 3.3 Apple 返回数据

**授权响应**：
```json
{
  "authorizationCode": "AUTH_CODE",
  "identityToken": "JWT_TOKEN",
  "user": "USER_ID",
  "email": "user@privaterelay.appleid.com",
  "fullName": {
    "familyName": "张",
    "givenName": "三"
  }
}
```

**Identity Token (JWT) 解析**：
```json
{
  "iss": "https://appleid.apple.com",
  "aud": "com.example.app",
  "exp": 1585000000,
  "iat": 1584996400,
  "sub": "USER_ID",
  "email": "user@privaterelay.appleid.com",
  "email_verified": true
}
```

**重要说明**：
- `user` 字段是用户的唯一标识
- `email` 仅在首次授权时返回
- `fullName` 仅在首次授权时返回
- 需要保存这些信息，后续不会再提供


### 3.4 服务端验证

**验证 Identity Token**：
```python
import jwt
import requests

# 获取 Apple 公钥
def get_apple_public_key(kid):
    response = requests.get('https://appleid.apple.com/auth/keys')
    keys = response.json()['keys']
    for key in keys:
        if key['kid'] == kid:
            return jwt.algorithms.RSAAlgorithm.from_jwk(key)
    return None

# 验证 Token
def verify_apple_token(identity_token):
    # 解析 header 获取 kid
    header = jwt.get_unverified_header(identity_token)
    kid = header['kid']
    
    # 获取公钥
    public_key = get_apple_public_key(kid)
    
    # 验证签名
    payload = jwt.decode(
        identity_token,
        public_key,
        algorithms=['RS256'],
        audience='com.example.app',
        issuer='https://appleid.apple.com'
    )
    
    return payload
```


### 3.5 隐藏邮箱处理

当用户选择隐藏邮箱时，Apple 会提供一个代理邮箱：
- 格式：`{random}@privaterelay.appleid.com`
- 邮件由 Apple 转发到用户真实邮箱
- 我们的系统直接使用这个代理邮箱


## 4. 账号绑定管理

### 4.1 绑定流程

```
用户已登录 (手机号/邮箱账号)
         ↓
进入"账号绑定"页面
         ↓
点击"绑定微信"
         ↓
发起微信授权
         ↓
获取微信用户信息
         ↓
检查该微信是否已绑定其他账号
         ↓
已绑定?
   /        \
 是          否
  ↓            ↓
提示解绑     创建绑定关系
旧账号       ↓
         绑定成功
```


### 4.2 解绑流程

```
用户进入"账号绑定"页面
         ↓
已绑定微信
         ↓
点击"解绑"
         ↓
验证身份 (密码/验证码)
         ↓
验证通过?
   /        \
 否          是
  ↓            ↓
返回错误    删除绑定关系
               ↓
            解绑成功
```

**解绑限制**：
- 必须保留至少一种登录方式（手机/邮箱/第三方）
- 解绑后，该第三方账号可以绑定其他账户


### 4.3 换绑流程

```
用户已绑定微信A
         ↓
点击"更换绑定"
         ↓
验证身份
         ↓
发起微信B授权
         ↓
确认换绑?
   /        \
 否          是
  ↓            ↓
取消       解绑微信A
               ↓
            绑定微信B
               ↓
            换绑成功
```


## 5. 数据存储

### 5.1 绑定表结构

```sql
CREATE TABLE user_oauth_bindings (
    id BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT UNSIGNED NOT NULL COMMENT '用户ID',
    provider TINYINT NOT NULL COMMENT '平台: 2=Apple, 3=微信, 4=抖音',
    provider_identifier VARCHAR(255) NOT NULL COMMENT 'OpenID',
    provider_union_id VARCHAR(255) COMMENT 'UnionID (微信特有)',
    provider_nickname VARCHAR(100) COMMENT '昵称',
    provider_avatar VARCHAR(500) COMMENT '头像URL',
    provider_token VARCHAR(500) COMMENT 'Access Token (加密)',
    provider_refresh_token VARCHAR(500) COMMENT 'Refresh Token (加密)',
    provider_token_expires DATETIME COMMENT 'Token过期时间',
    identity_data JSON COMMENT '原始用户信息',
    status TINYINT UNSIGNED DEFAULT 1 COMMENT '0=禁用, 1=启用, 2=删除',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_user_provider (user_id, provider),
    UNIQUE KEY uk_provider_identifier (provider, provider_identifier),
    INDEX idx_user_id (user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户第三方账号绑定表';
```


### 5.2 Token 加密存储

**加密方式**：AES-256-GCM

```python
from cryptography.fernet import Fernet

# 加密
fernet = Fernet(ENCRYPTION_KEY)
encrypted_token = fernet.encrypt(access_token.encode())

# 解密
decrypted_token = fernet.decrypt(encrypted_token).decode()
```


## 6. 异常处理

### 6.1 常见错误

| 错误场景 | 处理方案 |
|----------|----------|
| 用户取消授权 | 返回取消状态，不报错 |
| 授权过期 | 提示重新授权 |
| 获取用户信息失败 | 记录日志，返回友好提示 |
| 该第三方已绑定其他账号 | 提示"已绑定其他账号，请先解绑" |
| Token 过期 | 使用 Refresh Token 刷新 |


### 6.2 错误码

| 错误码 | 说明 |
|--------|------|
| 20001 | 第三方授权失败 |
| 20002 | 第三方授权取消 |
| 20003 | 该第三方账号已绑定其他用户 |
| 20004 | 获取第三方用户信息失败 |
| 20005 | 第三方 Token 过期 |
| 20006 | 不支持的第三方平台 |


## 7. 安全考虑

### 7.1 防伪造攻击

**验证 Identity Token**：
- Apple: 验证 JWT 签名
- 微信: 验证 access_token 有效性

**State 参数**：
- 防止 CSRF 攻击
- 生成随机字符串，回调时验证


### 7.2 隐私保护

- 第三方 Token 加密存储
- 不存储用户敏感信息
- 支持用户撤销授权
