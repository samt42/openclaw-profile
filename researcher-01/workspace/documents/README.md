# 技术调研文档

本目录存放项目中的技术调研报告和架构决策记录(ADR)。

## 目录结构

```
tech-research/
├── README.md           # 本文件
├── TEMPLATE.md         # 调研报告模板
├── YYYY-MM-DD-主题.md   # 具体调研报告
└── adr/                # 架构决策记录
    └── ADR-001-决策标题.md
```

## 使用规范

### 创建新调研

1. 复制 `TEMPLATE.md` 为新文件
2. 命名格式: `YYYY-MM-DD-技术主题.md`
3. 按模板填写调研内容
4. 完成后更新下方的调研索引

### 调研报告标准

- **完整性**: 覆盖背景、方案、对比、决策四个维度
- **客观性**: 优缺点都要客观陈述，避免偏见
- **可追溯**: 所有结论都要有依据，引用来源
- **时效性**: 注明调研时间，技术信息会过时
